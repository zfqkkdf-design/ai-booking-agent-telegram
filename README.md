# Telegram-бот запису на консультацію

Бот приймає повідомлення в Telegram і веде розмову через Claude. Вільний час він не називає зі своєї голови: спочатку питає календар Cal.com і відповідає лише тими слотами, які повернув API.

Клієнт пише боту. Обробник aiogram передає текст у Claude разом із двома інструментами: `get_available_slots` і `create_booking`. Поки модель просить інструмент, цикл викликає Cal.com і віддає їй результат цього виклику. В одному ході модель може і перевірити час, і створити запис.

`get_available_slots` робить GET на `https://api.cal.com/v2/slots` для числового типу події і діапазону дат. Клієнту показується київський час слота. У бронювання йде позначка `start_utc` з відповіді API, без переписування рядка.

`create_booking` відправляє POST на `https://api.cal.com/v2/bookings` лише коли є ім’я, пошта і конкретний слот. Час початку копіюється з відповіді попереднього інструмента. Якщо API слот не повернув, боту немає з чого зібрати запис.

Історія діалогу тримається окремо для кожного користувача і не довша за 20 повідомлень. Поки йде обробка, у чаті стоїть індикатор набору тексту.

Слот, годину і факт бронювання бот бере з відповіді Cal.com. У системній інструкції заборонено називати послуги і ціни, яких немає в списку в коді. Невідомий інструмент повертає помилку, а не вигадану відповідь.

## Стек

- Python 3.12
- aiogram 3
- Claude `claude-haiku-4-5-20251001` з викликом інструментів
- Cal.com API v2
- httpx

## Запуск

Залежності перелічені в `pyproject.toml`. Потрібні змінні оточення `ANTHROPIC_API_KEY`, `CAL_API_KEY` і `BOT_TOKEN`.

```bash
python main.py
```

У коді зараз два типи подій: аудит на 60 хвилин і ознайомчий дзвінок на 30 хвилин. Їхні ідентифікатори в Cal.com записані поруч із інструментами.
